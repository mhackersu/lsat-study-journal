# Skill

In Logical Reasoning, many test-takers read the question before the passage, believing it will help them find the answer more easily. But the test becomes easier when you focus on fully understanding the passage first. So read the passage first, take time to comprehend it, and then read the question. 

# Question

In Logical Reasoning, when should you read the question first?

A
When you have five minutes left in the section

B
When you plan to skip certain question types

C
When the passage is hard to read

D
When the passage is long

*E
Never

# Explanation

There are no exceptions. The test becomes easier when you see yourself as the boss. Realize that you can understand all the passages and that reading the questions first won’t help you.

A
Nothing changes at the end of the section. To be clear, you might not finish the section. You might have to guess on the remaining questions. But read the passage first for the questions you do attempt.

B
Don’t plan on skipping questions. They tend to get harder as you move through the section anyway.

C
How would you know that the passage is hard to read without reading at least some of it first? Even then, the question ain’t going to help you.

D
Again, the question ain’t going to help you. In fact, for longer passages, reading the question first can invite you to take misleading shortcuts as you start scanning for the conclusion or whatever else you think you need to find. 

E
Don’t ever read the question first. Always read the passage first—and you’ll start to see the difference.
